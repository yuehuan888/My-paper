## 摘要

让小波变换可学习，是小波域图像去噪的一个自然延伸。我们证明：在低剂量 CT 上，**这一延伸默认是失败的** —— 无约束的可学习分析/合成滤波器对在训练中会偏离可逆性，所得网络的表现**不比固定的 Haar 基更好**。我们的设计在 n = 5 个种子下可分辨 **0.136 dB** 的效应，而无约束臂与固定 Haar 的差距只有 **0.025 dB —— 低于该检出下限 5.6 倍** —— 因此我们把结论表述为一个**上界**而非"无差异"：任何真实差异都小于 **0.14 dB**，约为完美重构随后带来的收益的**一半**。我们追溯到其原因：训练后变换的重构误差达到 **11–18%**。并进一步证明这是**因果而非仅仅相关** —— 向完美重构臂注入一个同样量级的受控误差，会把它退化到固定 Haar 的水平。把完美重构**由结构保证**——即把小波参数化为提升格式，使逆变换复用正向滤波器——之后，学习才产生收益：**相对无约束学习 +0.30 dB（p = 0.0005，d_z = 4.67），相对固定 Haar +0.27 dB（p = 0.0004，d_z = 4.78）** —— 是大效应而非边际效应，且在两个数据划分上一致。

另外两个结果进一步定位了这个效应。**第一，变换其实学得很少**：从任何数值上完好的起点出发，训练都会收敛到一个很窄的、偏离 Haar 的漂移带；而从 **Haar 本身**出发，它会被**推远** —— 最优解略微偏离 Haar，这正是"自适应"在这里买不到多少东西的原因。我们也检验并**否定**了一个自然解释——"头部网络只是替变换补课"：PR 的优势并没有随着头部容量增长两个数量级而缩小。**第二，失效模式是悬崖而不是斜坡** —— 一旦正向变换的闭环误差超过信号本身，梯度就不再携带信息，训练无法自救（漂移 4.0 处停在 4.000 与 3.29 dB，而漂移 2.0 处可以完全恢复）。因此"是否落在数值包络内"是个二值问题，这也是有界化**必需**的原因 —— 以及为什么 bound 的取值比预想中更重要：我们的默认值代价是 **+0.10 到 +0.15 dB**，约等于整个 PR 效应的一半。

最终网络仅有 **2,159 个参数**，在 AAPM-Mayo 2016 上达到 **31.97 dB**，与**同等协议下训练的 RED-CNN 基线**相差 1.0 dB 以内，而参数量少 **857 倍**。

**关键词**：低剂量 CT、图像去噪、可学习小波、提升格式、完美重构、可逆性

## 1. 引言

低剂量 CT（LDCT）降低了辐射暴露，代价是噪声升高。RED-CNN [1] 这类深度去噪网络有效，但参数量大（约 10⁶ 量级），这限制了它在基层医疗机构常见的低资源工作站上的部署。因此轻量模型是有吸引力的。

小波域处理是分离噪声与结构的经典手段，近期工作进一步让小波本身**可学习**，以适配特定模态与剂量 [17]–[22]。本文问一个简单的问题：

> **让小波可学习，真的有用吗？**

近期可逆小波去噪方法 [19], [20] 把完美重构（PR）构建进了架构。但"这一结构**是否正是**让学习产生收益的原因"从未被检验过：先前工作**假设**了可逆性，因此无法观察到它的缺失。我们的答案来自一个受控三臂实验 —— 在固定容量、划分、调度与评测的前提下，把可逆性变成**可选项** —— 结论是：**只有当变换被结构性地保持可逆时，学习才产生收益。**

把小波参数化为**提升格式**（lifting scheme）[23], [24] —— 逆变换**复用**正向的预测/更新滤波器，而不是另一组参数 —— 之后，学习才产生收益：**相对无约束学习 +0.30 dB、相对固定 Haar +0.27 dB**，效应量很大（d_z ≈ 4.7），并在第二个划分与 SSIM 上复现。

反面的情形同样有信息量。无约束的可学习分析/合成滤波器对，其表现与固定 Haar 基**在统计上无法区分**。我们在措辞上很小心：该设计在 n = 5 个种子下可分辨 0.136 dB 的效应，而无约束–固定 Haar 的差距是 0.025 dB —— **低于该下限 5.6 倍**。因此我们报告的是一个**上界**而非"无差异"：任何真实差异都小于 **0.14 dB**，约为 PR 所带来收益的一半。一个功效不足的实验不可能分辨出 PR 所产生的那种效应。

**为什么**会失败，才是本文的实质。训练之后，无约束滤波器对在一次正–逆往返中丢失了 **11–18%** 的信号，而两个可逆臂都是 **1.6e-07**。我们证明这是**因果，而非仅仅相关**：在架构、容量与协议固定的前提下，我们向 PR 臂注入一个受控的闭环误差，它**单调地**退化到固定 Haar 水平（8.7% 误差 → 30.5500 dB，对照一个"什么都没学到"的臂为 30.5591 dB；每一档 p ≤ 0.007）。先前的可逆小波去噪方法观察不到这一状态，因为它们的设计使它**不可达**。

**贡献。**

1. **一个缺失的对照**，以及它揭示的负结果：在容量与协议固定的前提下，无约束的可学习小波相对固定 Haar 没有任何收益 —— 表述为 **0.14 dB 的上界**，而不是"无差异"。
2. **一个因果机制**，通过干预而非相关来确立：同样量级的闭环误差**足以**摧毁这个收益，且单调、显著（n = 5 种子，每一档 p ≤ 0.007）。先前的可逆小波去噪方法观察不到这一状态。
3. **一个数值包络，以及越界之后会发生什么。** 结构性完美重构在 float32 下**不会自动兑现**。我们从两个方向刻画这条边界。其一，对 taps 幅度做**受控扫描**：闭环误差从 |taps| ≈ 1.0 处的 3.6e-07 增长到 ≈ 5.3 处的 5.2e+00（*这是对参数域的受控分析，不是训练漂移的测量*）。其二，把 taps 初始化在距 Haar 一个已知距离处，我们证明越过这条边界是**悬崖**：在漂移 4.0 处正向变换输出的是噪声，梯度不携带信息，训练停在原地（最终漂移 4.000，3.29 dB），而漂移 2.0 处可以完全恢复。因此"是否在包络内"不是一个程度问题 —— 这就是我们要对 taps 做有界化的原因，也是为什么 bound 的取值比预想中更重要（§5.4）。
4. **变换到底学到了什么。** 从任何数值上完好的起点出发，训练都会收敛到一个**很窄的、偏离 Haar 的漂移带（≈ 0.65–0.78）**；而从 Haar **本身**出发，它会被推远。因此最优解略微偏离 Haar —— 这就是"学习"在这里买不到多少东西的具体原因。我们也检验并**否定**了"头部网络只是替变换补课"这一自然假设：PR 的优势并没有随着头部容量增长两个数量级而缩小。
5. **一个 2,159 参数的网络**，在同等协议下与 RED-CNN 基线相差 1.0 dB 以内，参数量少 **857 倍**。

## 2. 相关工作

### 2.1 低剂量 CT 去噪

RED-CNN [1] 这类卷积编解码器奠定了该领域，随后是对抗方法 [2], [3]，以及更近期的 Transformer 与扩散模型方法 [4]–[11]。这些方法提升了保真度，但参数量在 10⁵–10⁷。另一条路线转而追求效率：MLAR-UNet [13]、CT-Mamba [15]、AMFA-Net [16]、FMDNet [14] 与 MobileMamba-UNet [12] 都以远低的代价报告了有竞争力的结果，其中最后一个同样在小波域工作。我们认同效率目标，但问的是另一个问题 —— 不是*去噪器能有多小*，而是*让变换本身可学习到底有没有帮助*。

### 2.2 小波域与多分辨率去噪

小波收缩（wavelet shrinkage）[27], [28] 通过阈值化子带系数来分离噪声与结构。多级小波 CNN [17], [18] 把这一结构重新引入深度网络，近期 LDCT 方法把小波与扩散模型 [11] 或状态空间模型 [12] 结合。**在这些工作中，变换都是固定算子**，可学习容量位于其外围网络。

### 2.3 可学习变换与可逆性

另一条路线让变换本身可学习。LINN [19] 在一个**固定的**非抽取 Haar 变换周围学习提升格式的预测/更新步骤；WINNet [20] 更进一步，连切分算子本身也学习，并用 Cayley 变换约束其正交性，从而使完美重构由构造保持。**两者都把可逆性构建进了架构**。经典滤波器组理论 [25], [26] 给出完美重构条件，提升格式 [23], [24] 是按设计满足这些条件的标准构造；正交性则另被用于改善 CNN 的优化条件 [30]。

### 2.4 最接近的先行结果（正面处理）

WINNet 的 Table II 消融在自然图像 AWGN 去噪上比较了带/不带抽取的 Haar、多种尺寸的 DCT、以及 Cayley 学到的算子，结论是**学到的算子与固定 DCT 表现相近** —— 因此他们默认改用固定算子。

这与我们的负结果表面相似，所以我们在这里正面处理，而不是留给审稿人去发现。有两点区别很重要。**第一**，他们的学到算子被约束为正交，因此完美重构**始终成立**：他们的比较是在两个**可逆**变换之间，而我们的是在可逆与**不可逆**之间 —— 我们所诊断的那个失效状态，在他们的设计中根本不可达，而且两篇论文都**从未报告过任何闭环误差测量**。**第二**，他们的工作是"挑默认值"的消融，没有显著性检验；而我们的是五种子配对检验，带置信区间。

### 2.5 我们的定位

我们既没有提出新的小波，也没有提出新的架构 —— §3.2 的提升构造是 LINN 和 WINNet 的，而且 WINNet 已经在保持完美重构的前提下学习滤波器 taps。**真正新的是那个缺失的对照。**

先前的可逆小波去噪方法**假设**了结构性可逆，从未检验其缺失，因此无法报告"没有它会怎样"。**让可学习变换的可逆性变成可选项、固定容量与训练协议、并测量其后果** —— 以及解释它的那个横跨六个数量级的闭环误差差距 —— 才是本文的贡献。§5.2 会再回到与 WINNet 消融之间的残余张力。

## 3. 方法

### 3.1 总体结构

网络在小波域中工作：

```
含噪 CT x
  ↓ PR-LWT 分解（2 级，7 个子带）
  ↓ 逐子带残差预测：δ_b = head_b(band_b)
  ↓ 清理后的子带：clean_b = band_b − δ_b
  ↓ PR-LWT 重建
去噪结果 x̂
```

其中 x 为含噪输入，δ_b 为逐子带的残差预测。2 级分解得到七个子带：{LL₂, LH₂, HL₂, HH₂, LH₁, HL₁, HH₁}。

### 3.2 PR-LWT：可完美重构的可学习小波

我们使用**提升格式**。一维情形下，按奇偶切分：

```
分解：d = x_o − P(x_e)        s = x_e + U(d)
合成：x_e = s − U(d)          x_o = d + P(x_e)
```

**关键在于：合成复用与分解相同的 P 和 U。** 因此可逆性是**结构**的性质，而非所学数值的性质：对任意 P、U，`reconstruct(decompose(x)) = x` 在浮点精度内恒成立。

二维变换是可分离的（先沿高度、再沿宽度做提升）。我们初始化 P = [0,1,0]（恒等预测）与 U = [0,0.5,0]，再施加 √2 的输出缩放，使初始化**严格等于正交归一 Haar**（四个子带均已核验到 2×10⁻⁷）。

**参数有界化是必要的，不是可选的。** 我们参数化为

```
P = P_init + 0.5·tanh(θ_P)      U = U_init + 0.5·tanh(θ_U)
```

不加这个约束时，taps 会漂移到 |P| ≈ 5，此时 float32 下的闭环误差从 3.6×10⁻⁷ 恶化到 5.2×10⁰。完美重构在精确算术下无条件成立；**有界化才是让它在 float32 下可用的东西**。

**参数量**：2 级 × 2 方向 × 2 滤波器 × 3 taps = **24 个**。

### 3.3 子带去噪头

每个子带由一个轻量头处理（conv3×3 → ReLU → conv3×3，内部 16 通道），预测该子带的**残差**（有符号，末层无激活）。七个头共 2,135 个参数；完整网络共 **2,159** 个。

### 3.4 训练

损失：预测与真值之间的 L1。Adam，学习率 10⁻³，30 轮，128×128 随机图块，批大小 8。

## 4. 实验设置

### 4.1 数据

**AAPM-Mayo 2016 低剂量 CT 挑战赛** [31], [32]，3 mm B30 配对子集：10 位患者，2,378 对四分之一剂量 / 全剂量 512×512 切片。切片按 `ImagePositionPatient[2]`（z 位置）配对；**不能**按文件名配对，因为两侧的切片序号字段完全相同。

### 4.2 评测口径

AAPM 从未定义过 PSNR 口径（其官方指标是放射科医师阅片评分），该数据集上至少并存五种互不兼容的约定。我们采用 **RED-CNN / CTformer 谱系**的口径，该口径被六个公开仓库逐字沿用：

```
预处理   x = (HU + 1024) / 4096            （不裁剪）
评测     反归一化回 HU；预测与参考同时 clip 到 [−160, 240]
         PSNR = 10·log10(400² / MSE_HU)，data_range = 400
         SSIM 按 SSinyu/RED-CNN 的 measure.py
聚合     逐切片算指标后取平均
```

该口径下的 identity 基线为 L506 29.2489、L067 26.5576、合并 27.8630 dB。**我们不把它当作一次独立确认。** 这些数字由我们自己的实现算出，而据我们所知，在这个数据集上"跨已发表工作吻合到 0.01 dB"这件事**本身是不可达到的**：对同一队列的独立再分析之间相差可达 **~2 dB**（例如第三方在 L506 上报告 27.24 dB，而我们的是 29.2489），Eulig 等人的基准中与 identity 等价的参考值也偏离 0.8 dB。因此 AAPM-Mayo 上的跨论文 PSNR 带有约 2 dB 的噪声地板 —— 这正是本文的每一条主张都针对**同协议基线**、而非引用数字的原因。

### 4.3 数据划分

采用两个**按患者**的划分以证明稳健性：

## 5. 实验

### 5.1 主结果

| 划分 | 方法 | 参数量 | PSNR | SSIM |
|---|---|---|---|---|
| S1 | identity | — | 27.8630 | 0.8361 |
| S1 | **PR-LWT（本文）** | **2,159** | **30.8314 ± 0.0815** | **0.8762 ± 0.0011** |
| S1 | RED-CNN [1]（本文复现，同划分） | 1,848,865 | 31.8310 | 0.8824 |
| S2 | identity（L506） | — | 29.2489 | 0.8759 |
| S2 | **PR-LWT（本文）** | **2,159** | **31.9731 ± 0.0787** | **0.9041 ± 0.0008** |
| S2 | RED-CNN [1]（本文复现，同划分） | 1,848,865 | **32.9471** | **0.9090** |
| S2 | RED-CNN [1]（文献报告值） | ~10⁶ | ≈ 32.93 | — |
| S2 | CTformer [4]（文献报告值） | ~1.4×10⁶ | ≈ 32.9 | — |

**标"本文复现"的基线，是我们用完全相同的协议自己训练的** —— 相同划分、相同图块尺寸、批大小、优化器、调度与评测 —— 因此对比不再依赖于复现他人设定。由此有两点观察。

**第一，这是对我们协议的一次独立检验**：在对齐文献的 S2 划分上，我们复现的 RED-CNN 在 L506 上达到 **32.9471 dB**，与独立发表的、同一患者的 32.93 dB 相差 **0.02 dB**。也就是说，我们的实现与评测口径**是真正复现了参考结果，而不只是"看起来接近"**。

**第二，在这个匹配的对比下**，PR-LWT 在参数量少 **857 倍**（2,159 vs 1,848,865）的条件下，与 RED-CNN 相差 **0.97 dB**（S2）与 **1.00 dB**（S1）。我们明确写出：**PR-LWT 在 PSNR 上并未击败 RED-CNN**；本文检验的主张是*是什么让可学习变换产生帮助*，而不是达到最优性能。参数–PSNR 权衡见图 4，视觉对比见图 3。

#### 5.2.1 独立重新获取的数据，每臂十个种子

在最初的实验与本次写作之间，数据集被迫**从头重新获取**：AAPM 官方的 Box 分发不可达，接替它的 Kaggle 镜像在下载中途被撤下，最终使用的这份是从一个部分归档中重建的，其 3 mm B30 区域存在空洞（L067 缺 13 张切片，L506 缺 1 张，得到 **421 张**而非 435 张的测试集）。由于数据因此不同，所有主要结果都端到端重跑了一遍。

这件事反而带来了好处：它构成了一次**事实上的复现**，而它迫使的两处协议变更值得写明，因为**两处都是更正**。

**(a) 训练协议原本不可复现。** 随机图块裁剪取自一个未设种子的生成器，因此给定的 `--seed` 并不能复现一次运行；用同一个种子重复运行会相差约 0.04 dB。以下所有数字都来自更正后的、种子确定的流水线，它**逐位可复现**（已核验：同一种子两次运行给出十位小数完全相同的 PSNR）。

**(b) 重跑的功效更高。** 每臂十个种子而非五个，把检出下限从 **0.136 dB 收紧到 0.074 dB**（图 14）。图 10 把两次数据获取并排呈现；图 13 给出均值与 95% CI 随种子数累积的收敛过程。

| 划分 | 臂 | 原始（435 张，n = 5） | 重新获取（421 张，n = 10） |
|---|---|---|---|
| S1 | `pr` | 30.8314 ± 0.0815 | **30.8575 ± 0.0740** |
| S1 | `unconstrained` | 30.5341 ± 0.0305 | 30.5427 ± 0.0460 |
| S1 | `fixed` | 30.5591 ± 0.0256 | 30.5739 ± 0.0497 |

**重新获取数据上的配对比较：**

| 比较 | Δ (dB) | p | Cohen's d_z | \|Δ\|/MDES | 原始 Δ |
|---|---|---|---|---|---|
| `pr` − `unconstrained` | **+0.3148** | **<0.0001** | **+5.13** | **4.28×** | +0.2973 |
| `pr` − `fixed` | **+0.2837** | **<0.0001** | **+5.04** | **3.85×** | +0.2723 |
| `unconstrained` − `fixed` | **−0.0312** | **0.0163** | −0.93 | 0.68× | −0.0251（p = 0.113） |

**两个正结果都复现了，而且效应量更大**（d_z = 5.13 与 5.04，对照 4.67 与 4.78），排序不变。第三行**性质发生了变化**，我们如实报告：在原始数据上 `unconstrained` − `fixed` 的差距与零无法区分；在这里它变成一个**负方向的**边缘显著。因此无约束学习不只是没用，而是略微**有害** —— 不过我们不会去强调一个只有检出下限 0.68 倍的 0.03 dB 效应。

**这许可了什么、不许可什么。** 配对的**比值**干净地复现；绝对水平在两次数据获取之间不可直接比较，因为测试集小了 14 张，其 identity 地板也相应移动（27.8630 → 27.9220 dB）。上面每一个比较都是在**同一次获取内部**的同口径对比，这也正是我们使用它们的形式。

**效应量很大，不是边际效应。** 两个显著比较的 d_z 为 +4.67 与 +4.78（S1），远超 0.8 这个常规的"大"阈值。因此本文的主张不是 PR-LWT 买到了小幅提升，而是它让网络的移动幅度相对于种子间波动而言既大又一致。

**SSIM 复现了同样的排序。** 三臂格局不是 PSNR 的假象。在 SSIM 上，`pr` 达到 **0.8762 ± 0.0011**（S1）/ **0.9041 ± 0.0008**（S2），而另外两臂（S1）为 0.8725 / 0.8729：`pr` − `unconstrained` = **+0.0037**（p = 0.0008，d_z = +4.07），`pr` − `fixed` = **+0.0033**（p = 0.0016，d_z = +3.40），在 S2 上方向相同（两者均为 +0.0029，p = 0.030 / 0.015）。

一处诚实的瑕疵：在 SSIM 上，`unconstrained` − `fixed` 的差距在 S1 上**负方向**边缘显著（−0.0004，p = 0.039），而在 PSNR 上不显著（p = 0.113）；在 S2 上它恰为零（+0.0000，p = 0.985）。因此无约束学习**从不更好** —— 在一个划分上它可被检出地**更差** —— 但我们不会从一个在另一划分上消失的 4×10⁻⁴ 的 SSIM 差异中读出稳定效应。

> **可比性说明。** SSIM 由我们自己的实现计算（`gaussian_weights=True`，σ = 1.5，窗口 11，`data_range` = 400），对每条臂以及我们复现的 RED-CNN 都**同样使用**，因此本文**内部**的所有比较都是同口径的。它与参考 RED-CNN/CTformer 代码的 SSIM 是否一致**未经独立核验**，因此我们**不**把我们的 SSIM 与*已发表*的 SSIM 值比较。PSNR 口径则不同 —— 它经过了一次独立测量的检验（§5.1）。同样的谨慎也适用于跨论文的 PSNR：§4.2 记录了该数据集上约 2 dB 的跨论文噪声地板，因此这里所有定量比较都针对**同协议**基线 —— §5.1 的同划分 RED-CNN 复现，以及三臂消融的各臂 —— 而从不针对引用数字。

**这个实验能检出什么、不能检出什么（图 5）。** 由于负结果承载了论证的很大一部分，我们直接量化该设计的分辨力。对 80% 功效的配对 t 检验，n = 5 时的最小可检测效应（MDES）为 **0.136 dB**（S1），n = 3 时为 0.244 dB（S2）—— 它们就是上表中 |Δ|/MDES 的分母。由此得到两个推论：

- **PR 的收益是可检出的**：+0.272 dB 是 S1 检出下限的 **2.0 倍**。
- **零结果的差距不可检出**：0.025 dB 的 `unconstrained` − `fixed` 差距落在该下限的 **0.18 倍**处，即**低于** n = 5 所能分辨的水平 **5.6 倍**。

这把结论从"我们无法区分它们"锐化为一个**上界**：无约束学习与固定 Haar 之间的任何真实差异都*小于 0.14 dB*，而 PR 带来的收益是 0.27–0.30 dB —— 约为**整个实验分辨力的两倍**。因此这个负结果不是一个盲目实验的产物：实验的锐度足以看见 PR 所产生的效应，而在它缺席时什么也没看见。

**三个结论，在两个划分上完全一致：**

1. 施加完美重构约束，使可学习小波**显著优于固定 Haar**（+0.27 dB，p < 0.001）。
2. 它同时**显著优于无约束学习**（+0.30 dB，p < 0.001）。
3. **无约束学习与固定 Haar 无法区分**（p = 0.11 / 0.34；两个划分上置信区间均跨零）。

结论 3 是关键。它**不是统计功效不足的产物**，因为**同一个实验能在 p < 0.001 下分辨出 +0.27 dB 的差异**。无约束学习确实什么都没换来。

> **关于分析单元。** 测试集包含 435 张（S1）/ 211 张（S2）切片，但它们来自仅仅 2 位 / 1 位患者。同一患者的相邻切片高度相关，若把切片当作独立样本，显著性会被夸大数个数量级。因此上述所有检验都以**训练种子**为独立单元。这是刻意保守的做法。

**与 WINNet 切分算子消融的关系。** WINNet [20] 在一个表面相似的比较上给出了**相反**的结论：其用正交约束学习到的切分算子，在自然图像 AWGN 去噪上与固定 DCT 表现相当，于是他们默认采用了固定算子。我们的设定在多个维度上同时不同 —— 任务（LDCT vs 自然图像 AWGN）、变换族（一个**以 Haar 为初始化**的 2 级提升参数化，学习是从固定基线出发离开，而不是在匹配尺寸的所有正交矩阵中搜索）、以及评测（五种子配对检验带置信区间 vs 挑默认值的消融）。**仅凭已发表的数字，我们无法把这一分歧归因于其中任何单一因素**，因此我们把它标注出来，而不声称一个一般性结论。这个实验真正确立的结论更窄，我们相信也稳健：**在本架构与任务内，完美重构约束才是让可学习性产生收益的原因。**

### 5.3 机制：无约束学习到底做了什么

我们测量**训练完成后**的变换的分析–合成闭环误差（图 2a），取每个种子的最终 checkpoint（`experiments/verify_roundtrip.py --checkpoints`），在 S1 上每臂十个种子。图 2 的 (a) 面板展示这些结果，(b) 面板是下文描述的干预实验。

| 臂 | 小波参数 | 闭环误差（相对 L2），S1（n = 10） | S2（n = 3） |
|---|---|---|---|
| `pr` | 24 | **1.62e-07** ± 0.01e-07 | **1.65e-07** |
| `fixed` | 0 | 1.64e-07（各种子完全相同） | 1.64e-07 |
| `unconstrained` | 64 | **1.35e-01** ± 0.19e-01 | **1.45e-01** |

> **关于这项测量。** 闭环误差是在一个固定随机输入上探测的，因此它是**训练后变换**的性质而非测试集的性质 —— 这里唯一要紧的是种子数，而 S1 现在每臂有十个种子。`fixed` 臂按构造与种子无关（没有可学习参数），所以它的离散度为零。

无约束学习把变换推到了一个**每次正–逆往返丢失 11–18% 信号**的状态（S1 均值 13.5%，逐种子 11.4–17.9%；S2 均值 14.5%，逐种子 11.9–16.4%），而两个可逆臂则停在 **1.6e-07**（float32 极限）：**相差 5.9 个数量级**。网络于是必须一边去噪、一边补偿自己的变换。

**上面的比较是相关性的。** 无约束臂既丧失了可逆性、又表现如固定 Haar，但这本身不足以说明前者导致了后者。因此我们**直接做干预**：固定架构、容量与训练协议不变，向 **PR 臂**注入一个受控的闭环误差 —— 让它的**合成**步使用 `(1−ε)·U` 而**分解**仍用 `U`，从而在隔离条件下精确复现无约束臂自发产生的那个缺陷：

| 注入 ε | 实测闭环 | 测试 PSNR（S1） | 相对 ε=0 | 配对 *p* |
|---|---|---|---|---|
| 0（对照） | 1.6e-07 | 30.8314 ± 0.0815 | — | — |
| 0.111 | 5.5e-02 | 30.7142 ± 0.0508 | −0.117 | **0.0067** |
| 0.222 | 8.7e-02 | 30.5500 ± 0.0618 | −0.281 | **0.0010** |
| 0.444 | 1.2e-01 | 30.2850 ± 0.0459 | −0.546 | **<0.0001** |

性能随注入误差**单调下降**，且每一档都显著（配对 t 检验，独立单元 = 训练种子，n = 5）。在 **8.7%** 闭环误差处，PR 臂落到 **30.5500 dB** —— 正是固定 Haar 的水平（30.5591），也就是一个"什么都没学到"的臂的表现。**因此这个干预在因果层面支持了机制**：这个量级的误差不只是与失效相关，它**足以**造成失效。

**诚实边界。** 这条剂量–响应曲线比跨臂比较**更陡**：在 11.8% 误差处，注入臂达到 30.2850 dB，低于无约束臂（30.5341）也低于固定 Haar（30.5591）。无约束臂的失配同时存在于它的**分析**与**合成**两组滤波器中，而我们的注入只扰动合成侧 —— 两种缺陷量级相同、**结构不同**。因此我们声称的是**同量级下的充分性**，而**不是**精确复现无约束臂的误差。

PR-LWT 在保持完全自适应的同时，把闭环误差维持在 float32 极限。**这就是全部机制。**

### 5.4 变换到底学到了什么，以及 bound 在哪里咬合

前面的结果说明完美重构约束**足以**让学习产生收益。它们没有说明学到的变换长什么样，也没有说明 bound 需要收得多紧。两个实验回答这一点。

**这个任务有一个偏好的工作点，而且它不是 Haar**（图 16）。我们把提升 taps 初始化在距 Haar 初始化一个受控距离 d 处（θ₀ = atanh(d/β)，因此 |P − P_init| ≈ d），然后测量训练把它们留在了哪里（表见下）：

| 初始漂移 d | 训练后漂移 | 测试 PSNR |
|---|---|---|
| 0.00（Haar） | **0.775** | **31.034** |
| 0.50 | 0.709 | 30.983 |
| 1.00 | 0.773 | 30.776 |
| 2.00 | 0.654 | 30.578 |
| 4.00 | 4.000 *（卡住）* | **3.292** |

在初始变换数值上完好的范围内（d ≤ 2），训练收敛到一个**很窄的漂移带：0.654–0.775**（终点跨度 0.12，而起点跨度为 2.0；r = −0.75，即两个方向都向内收敛）。从 Haar **本身**出发时，训练把 taps **推远**到 0.775 —— 梯度并不认为 Haar 最优。诚实的解读是：**最优小波略微偏离 Haar，漂移约在 0.7 附近**，这也正是"学习"买不到多少东西的原因 —— 本来就没什么可学。我们把它作为实测行为陈述；与起点的残余相关（r = −0.75，而不是 −1）说明这个吸引子是**软的**，而非精确的。

**数值崩溃是悬崖，不是斜坡**（图 16b）。在 d = 4 处，初始变换的闭环误差就已经是 4.3×10¹ —— 正向过程输出的就是噪声。此时训练**什么都做不了**：漂移精确停在 4.000，网络达到 **3.29 dB**，即输出与输入无关。没有可恢复的梯度信号，因为网络收到的系数已经是垃圾。对照 d = 2（闭环 1.4×10⁻²），它可以恢复到 0.654 与 30.578 dB。这就是为什么有界化是**必需**而非仅仅审慎：跨过悬崖在**训练内部**是不可逆的。

**默认 bound 比它需要的更紧**（图 11、图 17）。扫描 β：

| Bound β | 漂移达到 | 测试 PSNR | 相对默认的 Δ | p |
|---|---|---|---|---|
| **0.5（默认）** | 0.230 | 30.858 | — | — |
| 1.0 | 0.293 | 30.986 | **+0.101** | **0.038** |
| 2.0 | 0.371 | 31.036 | **+0.151** | **0.029** |
| 4.0 | 0.651 | 31.050 | +0.165 | 0.058 |
| 8.0 | 0.775 | 31.034 | +0.149 | 0.062 |

bound 并不**裁剪**漂移（β = 0.5 时的利用率是 46%）；它**限制了优化器搜索的范围**，而它达到的漂移随 β 单调上升，把 PSNR 一起拉高。在 β = 0.5 —— 本文其它地方一直使用的值 —— 优化器停在漂移 0.23，远低于模型偏好的 ≈ 0.7，代价是 **+0.10 到 +0.15 dB**。这大约是整个 PR 效应的一半，而代价只是一个超参数。

> **对这一主张的边界。** 只有 β = 0.5 有 n = 10 个种子（即默认的 pr 臂本身），另外四档各有 n = 3，因此峰值的**位置**并未确立 —— 4.0 与 8.0 单独看只是边缘显著（p = 0.058、0.062）。上表中的 Δ 与 p 都是**同种子子集（种子 0–2）**上的配对检验；默认行报告的是全部十个种子，而它的 3 种子子集（漂移 0.228、30.885 dB）与 n = 10 估计只差 0.03 dB，说明基线不是被挑选出来的。（由 `runs/fix_pr_s*` 与 `runs/fix_bnd*` 重算 —— 早先那一行把子集的 0.229 / 30.885 印在了 n = 10 的标题下。）数据所支持的是：**默认值显著劣于 1.0 与 2.0**。我们把峰值当作名义值报告，不声称存在最优。

**一个我们检验并否定的假设**（图 15）。对整个负结果有一个自然的解释：头部网络可以**替代**变换 —— 给它们足够的容量，好的小波就不再重要。我们通过改变头部容量（`--n-conv`，94 → 2,159 → 18,399 参数）并测量 PR − fixed 的差距来检验它：

| 头部容量 | Δ（PR − 固定 Haar） | n |
|---|---|---|
| 94 | +0.186 | 3 |
| 2,159 | +0.284 | 10 |
| 18,399 | +0.304 | 3 |

这个差距随容量**增大**而非缩小（以 log₁₀ 参数计 r = +0.968）—— 与"替代"正好相反。因此站得住的表述是一个**稳健性**结论：PR 的优势在两个数量级的头部容量范围内持续存在（始终 0.19–0.30 dB）；头部变大时它不消失，变小时它也不放大。两端各只有 n = 3，所以我们不声称这个上升趋势本身。它的用途是**排除**"变换只是在替弱小的头部补课"这一解释。

## 6. 讨论与局限

**为什么我们不声称"无损"。** 完美重构只保证**系数未被修改**时的往返。去噪按其定义就是要修改系数，因此**完美重构并不蕴含一个无损的去噪器**。我们的主张更窄也更精确：完美重构约束移除了"变换本身"这个网络不得不建模的误差来源，而这正是使自适应能够产生收益的原因。

**局限。**

1. **单一数据集**（AAPM-Mayo）。在其它 CT 数据上的泛化未经检验 —— 其中 LoDoPaB-CT [33] 我们特别说明：它是**重建**基准（其 observation 是正弦图），若不先做 FBP 重建，无法直接用作零样本去噪测试。
2. **测试队列小**（S1 两位患者，S2 一位）。这正是我们逐患者报告、并以种子为分析单元的原因。作为量级参考，**患者间**的 identity 地板跨度为 **3.75 dB**（§4.4）—— 比本文报告的任何效应都大一个数量级 —— 这正是分析单元取种子而非切片的原因。
3. **30 轮的预算在收敛之前就截断了。** 几乎每一次运行的最优验证轮次都等于最后一轮（30/30），因此三条臂是在**固定预算**下比较，而不是在各自的最优点比较。比较是公平的 —— 每条臂拿到完全相同的预算 —— 但它比较的是学习**轨迹**，不是收敛解。更长的调度可能压缩或拉大这个差距；本文未做检验。
4. **同划分基线只覆盖 RED-CNN，且只有单个种子。** RED-CNN 由我们在自己的划分与协议下重新训练（§5.1），但只有 n = 1 个种子，而三条臂是 n = 5 / n = 3，因此对它无法做种子级配对检验，我们也不给出区间。CTformer 与其余方法仍引自文献，其训练集差异依然适用。
5. **注入的缺陷比真实的那个更简单。** 我们只扰动合成滤波器，而无约束臂的两组滤波器组是**各自独立漂移**的。干预确立的是**同量级下的充分性**（§5.3），而不是对该臂误差的精确复现。
6. **PR 臂的种子间离散度在数值上更大**（标准差 0.0815 vs 0.0305 与 0.0256 dB），尽管在 n = 5 下 Levene 检验未能证实异方差（p = 0.167 S1，0.630 S2）。我们标注它而不主张它：若属实，意味着 PR-LWT 的优势伴随略高的训练方差代价，需要更多种子才能定论。
7. **bound 是对着一个只在 n = 3 下显著的测量调出来的**（§5.4）。我们"β = 0.5 劣于 1.0–2.0"的主张建立在每档三个种子上；它隐含的 +0.10–+0.15 dB 应被视为**暂定**，直到用更多种子复现。我们报告它，是因为四个比较的方向一致，而不是因为它已经定论。
8. **我们的头部容量实验在两端都功效不足**（94 与 18,399 参数处各为 n = 3；只有默认的 2,159 处是 n = 10）。它足以**否定**替代假设 —— 这也正是我们使用它的目的 —— 但不足以支持 §5.4 中那个表观上升趋势。
9. **训练协议本身在这次工作中被更正过。** 随机图块裁剪原本取自一个未设种子的生成器，因此给定的 `--seed` 无法复现一次运行。本文报告的所有结果都来自更正后的、种子确定的流水线；这一更正让个别数字变化约 0.01–0.05 dB，更重要的是它**降低了方差**，而正是此前的方差掩盖了 §5.4 中的 bound 效应。
10. **未做下游任务验证**（如分割）。

## 7. 结论

我们问：让小波可学习，对 LDCT 去噪有帮助吗？答案是：**默认没有** —— 无约束的可学习小波表现得与固定 Haar 基一样好（在更正后的流水线上甚至略微更差），因为学习摧毁了变换的可逆性。把可逆性变成本身**由结构保证** —— 通过一个逆变换复用正向滤波器的提升格式 —— 才让自适应产生收益，而网络只有 2,159 个参数。

另外两个发现让图景更清晰。**变换确实学到了东西，但不多**：从任何数值上完好的起点出发，训练都收敛到一个很窄的、偏离 Haar 的漂移带（≈ 0.65–0.78），这就是收益有限的原因。而**数值失效模式是悬崖而不是斜坡** —— 一旦正向变换的闭环误差超过信号，系数就是噪声，梯度不携带信息，训练无法自救。这就是"有界化是必需的"的精确含义：不是因为缺少它性能会平滑退化，而是因为跨过边界在训练内部是不可逆的。

这个教训可以推广到本任务之外：**当一个被学习的部件理应可逆时，可逆性应当是结构性的，而不是寄希望于它自己成立** —— 而让这个结构可用的那个数值包络，值得被明确写出，而不是留在一个默认值里。
